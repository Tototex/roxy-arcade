Modular arcade with multiple games, leaderboards, and monthly prize support.

== Description ==

Roxy Arcade supports:

* Multiple games
* Combined and per-game leaderboards
* Guest play
* Logged-in score saving
* Monthly winner snapshot
* WooCommerce Subscriptions prize support
* GitHub auto-updates

== Installation ==

1. Upload the plugin ZIP to WordPress.
2. Activate the plugin.
3. Add the [roxy_arcade] shortcode to a page.
4. Create GitHub release tags beginning with v for packaged updates.
